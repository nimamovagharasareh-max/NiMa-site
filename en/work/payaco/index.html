Payaco office automation system

A web app that brings an elevator and escalator company's scheduled maintenance, repairs and finance into one place. It installs on mobile and is used every day.

ClientPayaco Elevator Co., Ahvaz
IndustryElevators & escalators
ServicesOffice automation
PlatformWeb app (PWA)

See the live system ↗

This is an internal system that only Payaco staff can sign in to; the link opens its login screen.

The challenge

The day-to-day work of an elevator service company, from scheduled maintenance and repairs to finance follow-ups, is usually scattered across paper, messaging apps and loose files. Payaco needed one integrated system to bring all of it together.

What we built

  • Comprehensive office automation system (app.payaco.org): an installable web app (PWA) that brings service, repair and finance work into one place.
  • Ongoing development: the system keeps improving release by release and is in daily use.

The result

Payaco's internal work now runs in a single system instead of being scattered across paper and messaging apps.
