# سایت NiMa — نسخه‌ی اول (کم‌هزینه)

سایت کاملاً استاتیک: فقط HTML و CSS، بدون سرور، دیتابیس، فریم‌ورک یا مرحله‌ی build. فونت‌ها (Montserrat و Vazirmatn) داخل خود سایت هستند تا به Google Fonts وابسته نباشد. حجم کل حدود ۴۵۰ کیلوبایت.

## صفحه‌ها
- `index.html` صفحه‌ی اصلی فارسی (پیش‌فرض، راست‌چین)
- `en/index.html` صفحه‌ی اصلی انگلیسی
- `work/payaco/` و `en/work/payaco/` نمونه‌کار پایاکو
- `404.html` صفحه‌ی خطا

## جاهایی که باید پر شود (در کد با `TODO(Nima)` مشخص شده)
1. لینک‌های تماس: `TELEGRAM_ID` و `EMAIL@EXAMPLE.COM` (هر دو زبان)
2. متن معرفی کوتاه نیما در بخش «درباره» (و در صورت تمایل عکس)
3. عدد واقعی نتیجه برای پایاکو، اگر وجود دارد (عدد ساختگی نگذاشتیم)

## انتشار رایگان (پیشنهاد: GitHub Pages)
1. در GitHub یک ریپوی **عمومی** بساز با نام دقیق `nimamovagharasareh-max.github.io`.
2. محتوای پوشه‌ی `site/` را در شاخه‌ی `main` قرار بده.
3. Settings → Pages → Source: «Deploy from a branch» → `main` / `(root)`.
4. سایت روی `https://nimamovagharasareh-max.github.io/` بالا می‌آید. هزینه: صفر.

## دامنه (باز، تصمیم با نیما)
بعداً با خرید دامنه (مثلاً `.ir` از nic.ir یا `.com`) یک فایل `CNAME` با نام دامنه اضافه می‌شود و رکوردهای DNS به GitHub Pages اشاره می‌کنند. هزینه فقط همان هزینه‌ی سالانه‌ی دامنه است.

## ویرایش
متن‌ها مستقیم در فایل‌های HTML هستند. رنگ‌ها و فونت‌ها در `assets/style.css` بالای فایل، مطابق NiMa-Brand-Brief.
